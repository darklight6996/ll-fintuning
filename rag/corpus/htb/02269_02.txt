Blind Injection Because I have an injection that returns different responses based on the injection, I can do a blind injection. This post gives an example, but you have to guess the fields in the database to make it work. I tried guessing that the username might be stored in uid with a username like 0xdf' or uid like 'b% (though the % needs to be encoded to %25 ), and it returned Invalid Credentials. When I try with 'a% , it returned Invalid fingerprint-ID. Now I have a way to brute force any column I can guess. I was able to guess objects “username”, “password”, and “fingerprint”.
