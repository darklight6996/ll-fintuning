To route DC02’s authentication through me, I’ll create a DNS record in darkzero.ext using the CREDENTIAL_TARGET_INFORMATION (CMTI) trick I’ve used in DarkCorp , Signed , and VulnCicada . This creates a record like DC021UWhRC...YBAAAA that embeds DC02’s target info in the hostname, so Windows treats authentication to it as if it’s going to the real DC02, triggering the local auth path with the empty NTLM3 message. With that record pointing to my attack box, I coerce DC02 to authenticate to the fake hostname, then a special fork of Impacket from dec0der that allows removing the MIC to reflect the auth back to DC02’s LDAPS. This gives me privileged LDAP access as DC02’s machine account, which I can use to get admin and SYSTEM on DC02.
