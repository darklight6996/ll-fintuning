An ACE takes the following format : ace_type;ace_flags;rights;object_guid;inherit_object_guid;account_sid;(resource_attribute) So I’ll start with the first one: (A;;KA;;;AU) The ACE type is A for ACCESS_ALLOWED_ACE_TYPE . There are no flags. The rights are KA , the registry key access rights of KEY_ALL_ACCESS . There’s no guid, inherit guid. Then the SID this applies to is AU , or SDDL_AUTHENTICATED_USERS or authenticated users. So any user that’s authenticated has full access to the registry through this service. The next string: (A;;CC;;;AU) This is to allow all authenticated users CC , which is a directory service object access right for SDDL_CREATE_CHILD or create child items.
