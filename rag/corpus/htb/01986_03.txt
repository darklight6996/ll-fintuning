IIS Short Names The other trick needed here is to use a trick to take advantage of Windows short names, which are referred to as the 8.3 file naming scheme because it limits each file name to eight characters, a dot, and then a three character extension. There was a really interesting paper that looks at how IIS handles 8.3 file names in earlier versions of IIS and .NET. The trick is to look at how the server responds to 8.3 names with wildcards, which it seems to process when ~ is in the path. Different servers may require different HTTP request methods to find the difference. This server doesn’t show the vulnerability with a GET request, but does show it with an OPTIONS request.
