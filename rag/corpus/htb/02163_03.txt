Forwarding that to the server, the response comes back 419: CSRF Checks Googling for Laravel 419 returns a bunch of links (like this one ) that talk about common reasons for this, and one is a CSRF token failure: CSRF token verification failure The most common reason for the 419 error is CSRF token failure. Cross-site request forgery token is a unique, encrypted value generated by the server. Laravel generates a CSRF token for each user session. The token verifies the user by requesting the application. So always include a CSRF token in the HTML form to validate the user request. The VerifyCsrfToken middleware automatically crosses checks the token in the request to the token stored in the session. In addition to CSRF token verification, the VerifyCsrfToken middleware also checks the X-CSRF-TOKEN request
