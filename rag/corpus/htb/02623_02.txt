I’m using two less common things here. First, since ffuf only takes files as wordlists, I’m using bash process substitution to generate temp files full of the output of seq commands to generate lists of numbers. Next, with multiple -w parameters, I can use the format -w <filename>:<marker> to specify a marker for each list. In this case, I’m using COUNT for the counter from 0 to 999, and YEAR for the year (from 2020 - 2026). By default, ffuf will try all possible combinations, which is what I want here.
