The project is pretty small: rkon is a public library for the Source RCON Protocol , designed for game servers. From the docs: The Source RCON Protocol is a TCP/IP-based communication protocol used by Source Dedicated Server , which allows console commands to be issued to the server via a “remote console”, or RCON. The most common use of RCON is to allow server owners to control their game servers without direct access to the machine the server is running on.
