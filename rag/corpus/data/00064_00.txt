TECHNIQUE / QUESTION:
How do you start the pentest on the Dog box?

CONTEXT:
You have the credentials for the user account j.fleischman with the password J0elTHEM4n1990!.

METHOD / ANSWER:
Command: `netexec smb dc01.fluffy.htb -u j.fleischman -p 'J0elTHEM4n1990!'`
Explanation: This command authenticates against the SMB service on the target, providing access to the Domain Controller.
