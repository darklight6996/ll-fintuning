**Assessment Phase**: Domain Credential Extraction.
**Core Principle**: The `ntds.dit` file contains all domain user password hashes. With `Replicating Directory Changes` permissions, this can be extracted remotely via DCSync.
**Actionable Steps**:
1.  **Extract Domain Hashes**: Use Mimikatz (`lsadump::dcsync`) or Impacket's `secretsdump.py` with appropriate credentials.
    *   **Reasoning**: These tools simulate domain replication to request and extract password hashes for all domain users from the Domain Controller. This provides material for Pass-the-Hash attacks, credential cracking, or Golden Ticket creation.
