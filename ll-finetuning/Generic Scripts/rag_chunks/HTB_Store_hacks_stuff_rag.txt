It looks to be the encrypted copy. Theory My theory of the website at this point is that site is encrypting files and storing them in /tmp , which isn’t meant to be available on the HTTP server. When a file is requested via /file/<filename> , the site is getting the encrypted file from /tmp , decrypting it, and returning it. That explains why the raw data is stored in the link, so it only has to be decrypted once.
