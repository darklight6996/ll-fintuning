Silver Ticket Background A silver ticket is a forged Kerberos service ticket (TGS) created using the NTLM hash of a service account. Unlike a golden ticket (which forges a TGT using the krbtgt hash), a silver ticket targets a specific service. In this case, because I have the NTLM hash (or the raw password which makes it trivial to calculate the NTLM hash) of the mssqlsvc account, I can craft service tickets (TGS) for the MSSQL service. TGS as mssqlsvc I’ll start by proving I can forge a ticket for a user I know, mssqlsvc. To create a ticket, I’ll need: The NTLM hash of the service account password.
