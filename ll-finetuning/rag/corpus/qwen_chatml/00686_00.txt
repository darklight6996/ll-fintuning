**Assessment Phase**: Configuration File Discovery.
**Core Principle**: Applications store connection strings, secrets, and settings in configuration files that are often accessible or poorly protected.
**Actionable Steps**:
1.  **Retrieve Web Config**: `curl http://<target>/<path_to_config>`
    *   **Reasoning**: Common configuration files like `web.config`, `.env`, `config.php`, or `application.properties` may contain database credentials, API keys, or other secrets in plaintext or easily reversible formats.
**Guidance for Novel Context**: The exact path varies by framework. Use directory traversal (`../../../`), known default locations, or fuzzing to discover files. Also search file systems with `grep -r "password" /var/www/ 2>/dev/null` when you have shell access.
