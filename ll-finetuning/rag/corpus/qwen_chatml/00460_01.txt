Leveraging Password Dumps
Attackers can leverage password dumps from previous breaches. There are
a number of ways that attackers can get access to such password dumps.
These sources include Pastebin, dark web sites, and even GitHub in some
cases. Different tools and websites make this task very easy. An example of
a tool that allows you to find email addresses and passwords exposed in
previous breaches is h8mail. You can install h8mail using the pip3 install
h8mail command, as demonstrated in Example 9-15. This example also
shows the h8mail command-line usage.
