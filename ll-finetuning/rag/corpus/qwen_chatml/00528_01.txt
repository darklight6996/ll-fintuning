is an open-source web vulnerability scanner that has been around for many
years. It’s not as robust as the commercial web vulnerability scanners;
however, it is very handy for running a quick script to enumerate
information about a web server and the applications it is hosting. Because
of the speed at which Nikto works to scan a web server, it is very noisy. It
