AI-Created Scanner Templates
The ProjectDiscovery Nuclei Scanner is a fast and extensible open-source
vulnerability scanner designed to identify and mitigate security
vulnerabilities across modern applications, infrastructure, cloud platforms,
and networks.
Nuclei uses a template-driven approach, where each template is a YAML
file that defines the steps needed to detect specific vulnerabilities. This
approach allows for highly customizable and targeted scans. It also supports
a massive library of community-curated templates, which are continually
updated to include the latest vulnerabilities in many systems.
