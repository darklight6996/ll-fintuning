There’s a ton of languages that are built to operate with .NET , including: C# C++/CLI IronPython VB.NET PowerShell Anything running inside the .NET CLI is known as managed code. In contract, languages that interact directly with the hardware are known as unmanaged code. Profiling In the context of the .NET CLR, Microsoft defines a profiler as: a tool that monitors the execution of another application. It can be any DLL that consists of functions that receive and send messages to and from the program using the CLR API.
