Backrest Overview On logging into Backrest as backrest_root with the password above, there’s nothing really here: Backrest is a GUI wrapper around restic , a command line backup utility. There are two objects in Backrest, Plans and Repositories. A repository is a storage location where backup data is kept, and the encryption keys that go with it. A plan is a configuration that defines what data is to be backed up, how often, and retention information. Escalation Paths There are multiple ways to get execution from Backrest. I’ll show three: Reading SSH key via backup. Abusing Backrest hooks. Injecting into a restic command.
