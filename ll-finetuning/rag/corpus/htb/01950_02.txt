Bad Successor Background Researchers at Akamai identified an issue they named Bad Successor that targets delegated Managed Service Accounts (dMSA), a feature that was added in Windows Server 2025. A dMSA account falls into the managed service account family: Type Introduced Purpose sMSA (standalone) Server 2008 R2 Auto-rotating password, tied to one machine gMSA (group) Server 2012 Same, but shared across multiple machines dMSA (delegated) Server 2025 Designed to replace legacy service accounts via a seamless migration Even today (almost a year after its release), searching for “Windows server 2025 exploit” returns the Akamai blog as the top answer: Microsoft originally said this wasn’t an issue, but after release did patch it, and Bad Successor got the CVE ID CVE-2025-53779. BadSuccessor abuses the dMSA migration feature introduced in Windows Server 2025.
