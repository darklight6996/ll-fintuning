DATABASE db-drop sql-drop Drop the current database and recreate an empty database with the same details. This could be used prior to import if the target database has more tables than the source database. db-export dbex, db-dump, sql-export, sql-dump Export the database as a compressed SQL file. This uses the --no-tablespaces option by default. db-import dbim, sql-import Import an SQL file into the current database.
