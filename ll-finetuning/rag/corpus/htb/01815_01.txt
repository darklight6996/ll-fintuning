ffuf scan to brute force all possible ports. This is a bit tricky for two reasons: I have to include the Content-Type header, or the site doesn’t process the POST data and it returns the page with no results. ffuf doesn’t have a range input the way that wfuzz did, so I have to make a wordlist of numbers to put in. I’ll use the seq command, and I like to use process substitution to do it inline. <( command ) tells bash to handle the output of command as if it were a file. The other args I’ll use are: -u http://10.129.234.87/index.php - The URL to send to. -d url=http://%3A%2F%2Flocalhost:FUZZ - The POST data, URL-encoded. -fr 'for everyone' - Filter out responses with the string “for everyone” to get just the open ports.
