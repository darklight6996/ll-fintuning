CVE-2022-37706 Background CVE-2022-37706 is a vulnerability in: enlightenment_sys in Enlightenment before 0.25.4 allows local users to gain privileges because it is setuid root, and the system library function mishandles pathnames that begin with a /dev/.. substring. The discoverer of this vulnerability did a really nice writeup with a POC on GitHub. Basically there’s a place where enlightenment_sys calls system(cmd) , where cmd is a string that includes user input. To get to that point, it must be invoked as enlightenment_sys mount with some specific mount options and then a filename.
