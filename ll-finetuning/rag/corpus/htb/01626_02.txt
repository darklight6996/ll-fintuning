However, one of the really smart protections that Linux put in place is that when LD_PRELOAD is used, any setuid privileges are dropped. This is where the fact that ldconfig is setuid allowing me to run it as root comes in handy. I can use this to configure where the binary looks for libraries, and give it one of my own instead of the one it currently looks for.
