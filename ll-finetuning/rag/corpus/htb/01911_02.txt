I was able to do some scanning using TCP in a loop: www-adm@webserver:/var/www/html$ for i in { 1..254 } ; do ( /tmp/nping --dest-port [ port] -c 1 172.18.0. ${ i } | grep "completed" & ) ; done I found this page which has a comma separated list of the top 1000 and top 100 ports, so I grabbed the top 100 and put it in there, and ran it. The scans all run in the background, so it immediately returns, and the results come in over time.
