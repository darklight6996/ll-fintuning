I’ll just start a container, and mount the root file system into it. The following command will start that image as a container, with the root filesystem of Cache mounted on /mnt inside the container, and drop me at a Bash shell: luffy@cache:~$ docker run -v /:/mnt -i -t ubuntu bash root@67fd1a66bece:/# Now I can access root.txt : root@67fd1a66bece:/mnt/root# cat root.txt e9f560a0************************ root Shell There’s a ton of ways to go from file system access to shell.
