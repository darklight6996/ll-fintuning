ng to JSON To get this into a format I can analyze, I’ll convert the events to JSON. I played with a few different tools from GitHub to do this, but liked evtx_dump from this repo by omerbenamram . I’ll download the latest release and drop it in a folder in my boxes path. The trick is to use the output format jsonl and not json . json will include lines with record numbers that breaks tools like jq when it tries to parse it. jsonl puts it all on one line of JSON, which jq can then parse: oxdf@hacky$ evtx_dump security.evtx -o jsonl -t 1 -f security.json oxdf@hacky$ cat security.json | jq . | head { "Event": { "#attributes": { "xmlns": "http://schemas.microsoft.com/win/2004/08/events/event" }, "System": { "Channel": "Security", "Computer": "eForenzics-DI", "Correlation": null, "EventID": 1102, Log Summary I’ll start by getting a feel for the different types of logs present and their frequency: oxdf@hacky$ cat security.json | jq -r '.Event.System.EventID' | sort -nr | uniq -c | sort -nr 5217 4673 4266 4703 2972 4658 2319 4656 752 4946 685 4688 657 4689 612 4690 ...[snip]...
