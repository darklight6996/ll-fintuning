This is important, because while I can’t create folders through Ajenti, I can create this file in the sysadm home directory. ssh Key Pair So I can create a set of RSA keys with ssh-keygen , and upload the public key into /home/sysadm/access . If I try to connect, it won’t work yet. That is because the default file permissions on the file are 666, or RW for everyone. sshd doesn’t trust that file because that’s too open.
