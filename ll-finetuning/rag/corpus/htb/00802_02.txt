According to the docs , the database is stored in files in a directory of the same name as the DB: A database directory contains the following, as shown in Figure 2 : log [directory] - Contains files that make up the database transaction log, used internally for data recovery (not the same thing as the error log). seg0 [directory] - Contains one file for each user table, system table, and index (known as conglomerates). service.properties [file] - A text file with internal configuration information. tmp [directory] - (might not exist.) A temporary directory used by Derby for large sorts and deferred updates and deletes. Sorts are used by a variety of SQL statements.
