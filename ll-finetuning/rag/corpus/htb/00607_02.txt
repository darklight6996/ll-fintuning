Simply changing the if back should suffice: For this change to show up on the running server, I’ll need to restart the node process. ps shows it running, with a parent process of pm2 : Click for full size image PM2 is a process manager for Node.JS. To see the process, I’ll drop to a shell as www-data and run pm2 list . If I just run su www-data , it fails: root@awkward:/# su www-data This account is currently not available. That’s because www-data’s shell is set to nologin , which just prints a message and exits: root@awkward:/# grep www-data /etc/passwd www-data:x:33:33:www-data:/var/www:/usr/sbin/nologin root@awkward:/# nologin This account is currently not available.
